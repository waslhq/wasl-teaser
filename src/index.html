The platform

One platform. Every kind of traffic.

A single governed spine for models, agents and services — so policy, identity and cost look the same everywhere.

AI Gateway01

Govern every model call

OpenAI-compatible access to OpenAI, Anthropic, Gemini and Bedrock — with quotas, cost caps, guardrails, PII redaction and a semantic cache.

MCP Gateway02

A front door for your agents

Expose APIs and flows as MCP tools — scoped per agent, token-exchanged, rate-limited and audited on every call.

API Gateway03

Route and govern every call

HTTP routing with a JavaScript flow runtime and 24 built-in policies for auth, rate limits, transforms and audit.

Event Gateway04

Streaming over plain HTTP

Produce and consume event streams with SSE and long-poll — governed, multi-tenant and broker-agnostic.

Worker05

Async work, off the request path

A job runtime for long-running flows, scheduled tasks and event-driven fan-out, scaled independently of your traffic.

Studio & Portal06

Design, deploy and observe

WASL Studio to build and operate, plus a developer portal with API keys, catalogs, analytics and an OAuth 2.1 server.

Built to operate

Runs where your business needs it.

Separate management from traffic, place runtimes in your infrastructure, and keep every change reviewable.

01

Fleets & immutable revisions

Every change is a versioned revision bound to a fleet — deploy, promote and roll back atomically.

02

Runtimes that fail apart

API, AI, Event, Worker and MCP run as separate processes, so a slow model call never slows your APIs.

03

Multi-tenant by design

Tenant isolation with role-based access, so teams and customers share a platform, not each other’s data.

04

Kubernetes-native

Helm workloads, health probes, network policies and resource limits — placed where your business needs them.

05

Pick the cheapest path

Each API chooses direct proxy, transform, composition, scripted flow or mock — only as heavy as it needs to be.

06

See what happened

Distributed tracing, metrics and usage analytics, with revisions and connections you can inspect in Studio.
